# 🌸 HerGlow

### Your Health. Your Beauty. Your Glow.

HerGlow is a women's wellness web application that brings
beauty, women's health, nutrition, mental wellness and
self-care into one platform.

## ✨ Planned Features

- 🧴 Skin type quiz
- ✨ Personalized skincare routine
- 🌸 Women's cycle tracker
- 📚 Beauty and wellness information
- 💧 Daily habit tracker
- 📊 Glow Score
- 🧘 Mood and self-care tools
- 👤 User authentication
- 📈 Personalized wellness dashboard

## 🛠️ Technology Stack

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MongoDB
